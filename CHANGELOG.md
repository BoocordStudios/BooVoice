# Changelog

All notable changes to BooVoice are documented in this file.

The project follows [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-09-01

### Added

- Temporary personal voice channels created from a configurable lobby
- Automatic cleanup when a personal channel becomes empty
- Per-server lobby, destination category, and name-template configuration
- Owner-only `/limit` and `/rename` commands
- Persistent local configuration and ownership state
- Automated tests, dependency auditing, and CI for Node.js 22 and 24
